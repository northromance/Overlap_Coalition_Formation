# Huo2025算法资源效用计算修复说明

**修复日期**: 2026年1月13日  
**修复目标**: 将Huo2025算法的效用计算改为基于资源分配比例的方式，并修复联盟成员ID获取错误

---

## 一、问题分析

### 1.1 原始问题

Huo2025算法原本使用简单的效用计算方式：
```matlab
utility = (revenue / 成员数) - cost
```

这种方式不考虑资源分配和完成度，与SA算法的评估标准不一致，导致算法对比不公平。

### 1.2 关键Bug

**核心错误**: `Value_utility.m` 中将联盟成员的**列索引**误当作 **agent ID** 来访问 `agents` 数组。

```matlab
% 错误代码
for i = 1:length(numberofcoworker)
    member_id = numberofcoworker(i);  // ? 这是列索引，不是agent ID
    if isfield(agents(member_id), 'resources')
        ...
    end
end
```

**问题根源**:
- `numberofcoworker = find(Value_data.coalitionstru(row,:) ~= 0)` 返回的是**列索引**
- 但 `coalitionstru(j, :)` 存储的值是 **agent ID**
- 应该使用 `coalitionstru(row, col_idx)` 来获取真正的 agent ID

### 2.2 新的效用计算公式

#### 个体效用公式

$$\text{utility}_n(C) = r_n(C) \times V_C \times D_C - \text{cost}$$

其中：

| 符号 | 公式 | 说明 |
|------|------|------|
| **$D_C$** | $D_C = \frac{1}{Z_c} \sum_{k=1}^{K} \min\left(\frac{\text{allocated}_k}{\text{demand}_k}, 1\right)$ | 资源完成度（上限1.0） |
| **$r_n(C)$** | $r_n(C) = \frac{\|\mathbf{A}_n\|}{\sum_{i \in C} \|\mathbf{A}_i\|}$ | 智能体n的资源贡献比例 |
| **$V_C$** | $V_C = \sum_{j=1}^{3} v_j \times b_j$ | 基于belief的期望价值 |
| **$\text{cost}$** | $\text{cost} = d_{n,task} \times \alpha$ | 飞行距离×燃料消耗率 |

说明：
- $Z_c$: 任务有非零需求的资源类型数量
- $\|\mathbf{A}_n\|$: 智能体n资源向量的L2范数
- $b_j$: 智能体对任务类型j的信念概率

#### 联盟总效用公式

$$\text{coalition\_utility}_j = V_{C_j} \times D_{C_j} - \sum_{i \in C_j} \text{cost}_i$$

$$\text{net\_profit} = \sum_{j=1}^{M} \text{coalition\_utility}_j$$

#### 修改点2: 正确获取联盟成员ID ?核心修复
```matlab
% 从联盟矩阵中获取真正的成员agent ID列表
% numberofcoworker是列索引，需要从coalitionstru中获取实际的agent ID
member_ids = [];
for i = 1:length(numberofcoworker)
    col_idx = numberofcoworker(i);
    if col_idx > 0 && col_idx <= size(Value_data.coalitionstru, 2)
        agent_id = Value_data.coalitionstru(numberrow, col_idx);  // ? 正确获取
        if agent_id > 0 && agent_id <= length(agents)
            member_ids = [member_ids, agent_id];
        end
    end
end
```

#### 修改点3: 计算资源完成度D_C
```matlab
% 计算联盟总资源
total_resources = zeros(1, K);
for i = 1:length(member_ids)
    member_id = member_ids(i);
    if isfield(agents(member_id), 'resources')
        member_resources = agents(member_id).resources(:)';
        if length(member_resources) >= K
            total_resources = total_resources + member_resources(1:K);
        elseif ~isempty(member_resources)
            total_resources(1:length(member_resources)) = ...
                total_resources(1:length(member_resources)) + member_resources;
        end
    end
end

% 计算完成度
Z_c = nnz(demand > 1e-9);
if Z_c == 0
    D_C = 1;  // 无需求时完成度为1
else
    D_C = 0;
    for k = 1:K
        if demand(k) > 1e-9
            ratio = min(total_resources(k) / demand(k), 1.0);
            D_C = D_C + ratio;
        end
    end
    D_C = D_C / Z_c;
end
```

#### 修改点4: 计算资源贡献比例r_n(C)
```matlab
% 智能体n的资源范数
if isfield(agents(numbercolumn), 'resources')
    agent_resources = agents(numbercolumn).resources(:)';
    if length(agent_resources) >= K
        A_n = norm(agent_resources(1:K));
    else
        A_n = norm(agent_resources);
    end
else
    A_n = 1;  // 默认贡献
end

% 所有成员资源范数之和
total_norm = 0;
for i = 1:length(member_ids)
    member_id = member_ids(i);
    if isfield(agents(member_id), 'resources')
        member_resources = agents(member_id).resources(:)';
        if length(member_resources) >= K
            total_norm = total_norm + norm(member_resources(1:K));
        else
            total_norm = total_norm + norm(member_resources);
        end
    end
end

% 贡献比例
if total_norm > 1e-9
    r_n_C = A_n / total_norm;
else
    r_n_C = 1 / max(length(member_ids), 1);  // 平均分配
end
```

#### 修改点5: 最终效用计算
```matlab
% 期望价值
V_C = tasks(numberrow).WORLD.value(1)*Value_data.initbelief(numberrow,1)...
    + tasks(numberrow).WORLD.value(2)*Value_data.initbelief(numberrow,2)...
    + tasks(numberrow).WORLD.value(3)*Value_data.initbelief(numberrow,3);

% 收益 = r_n(C) × V_C × D_C
revenue = r_n_C * V_C * D_C;

% 移动代价
distance = sqrt((agents(numbercolumn).x-tasks(numberrow).x)^2 ...
              + (agents(numbercolumn).y-tasks(numberrow).y)^2);
cost = distance * agents(numbercolumn).fuel;

% 最终效用
if (revenue - cost) > 0
    agentutility = revenue - cost;
else
    agentutility = 0;
end
```

## 四、关键特性

### 4.1 资源分配策略
- 如果一个智能体参与联盟，会将**全部对应资源**分配给该任务
- 资源完成度 $D_C$ 上限为 1.0（即使资源超过需求也不会额外加分）

### 4.2 健壮性提升
- ? 处理 `Value_Params.K` 缺失的情况
- ? 处理智能体资源长度不足的情况
- ? 处理空联盟的情况
- ? 处理零需求任务的情况（完成度设为1）
- ? 处理零资源总量的情况（平均分配贡献比例）

### 4.3 与SA算法的一致性
- ? 相同的资源完成度计算逻辑
- ? 相同的资源贡献比例计算方式
- ? 相同的期望价值计算方法
- ? 便于公平对比算法性能

## 五、修改前后对比

### 原版Huo算法效用计算
```matlab
% 简单的平均分配
individualrevenue = revenue / length(numberofcoworker);
cost = distance * fuel;
agentutility = individualrevenue - cost;
```

**问题**：
- ? 不考虑资源贡献差异
- ? 不考虑资源完成度
- ? 存在索引错误bug

### 新版资源效用计算
```matlab
% 基于资源的效用
revenue = r_n_C * V_C * D_C;  // r_n:贡献比例, V_C:期望价值, D_C:完成度
cost = distance * fuel;
agentutility = revenue - cost;
```

**优势**：
- ? 考虑智能体资源贡献差异
- ? 考虑联盟资源完成度
- ? 修复索引错误
- ? 与SA算法一致，便于公平对比
