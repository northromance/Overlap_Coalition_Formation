# 贪心基线算法 (Greedy Baseline)

## 算法说明

这是一个简单的贪心基线算法，用于与其他复杂算法进行对比。

## 算法流程

1. **任务排序**：按任务优先级从高到低处理任务
2. **智能体选择**：对每个任务，按距离从近到远选择智能体
3. **资源分配**：逐个添加智能体到联盟，直到满足任务资源需求
4. **效用计算**：基于任务价值、资源满足度和距离成本计算效用

## 效用函数

```
效用 = Σ (任务价值 × 资源满足度 - 距离成本)
```

其中：
- 资源满足度 = min(已分配资源/需求资源) for all 资源类型
- 距离成本 = 联盟成员到任务的总距离 × 0.1
- 只有满足度 ≥ 80% 的任务才计入效用

## 算法特点

### 优点
- 计算速度快，时间复杂度 O(M×N×K)
- 实现简单，易于理解
- 不需要迭代优化，一次遍历即可完成

### 缺点
- 局部最优解，不保证全局最优
- 不考虑任务间的资源竞争
- 后处理的任务可能因资源耗尽而无法完成
- 不考虑智能体能量约束

## 使用方法

### 单独运行
```matlab
% 初始化场景
[agents, tasks, Value_Params, ~, ~] = initialize_scenario(2437);
AddPara.control = 1;

% 运行贪心算法
[Value_data, history_data] = Greedy_Baseline_main(agents, tasks, AddPara, Value_Params);

% 查看结果
fprintf('总效用: %.2f\n', Value_data(1).totalvalue);
```

### 在对比框架中使用

在 `Compare_Algorithms.m` 中取消注释或添加：

```matlab
struct('name', '贪心基线', ...
       'func', @Greedy_Baseline_main, ...
       'folder', 'Com_Baseline', ...
       'enabled', true, ...
       'color', [0.5, 0.5, 0.5]);
```

## 作为基线的意义

该算法作为对比基线，可以用来评估：
1. 其他算法相比简单策略的改进程度
2. 复杂优化算法的必要性
3. 计算成本与性能提升的权衡

## 输出格式

符合标准的 `Value_data` 和 `history_data` 格式，可直接用于对比框架。
