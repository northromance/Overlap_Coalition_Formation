```matlab
%% 4. 信念更新阶段：基于观测结果更新信念（贝叶斯更新）

```

**修改后**:
```matlab
%% 4. 信念更新阶段：基于观测结果更新信念（贝叶斯更新）
% 根据开关决定是否更新信念
if enable_belief_update
    fprintf('[Qi2023] 第 %d 轮：更新信念...\n', round);
    Value_data = AgentOps.update_belief_from_observations(Value_data, Value_Params);
else
    fprintf('[Qi2023] 第 %d 轮：跳过信念更新（使用初始信念）\n', round);
end
```

**说明**:
- 当开关为 `false` 时，跳过贝叶斯信念更新
- 智能体将继续使用初始信念进行决策

#### 2.4 控制信念广播阶段

**修改位置**: 第 236-244 行

**修改前**:
```matlab
%% 6. 信念广播：智能体之间共享信念
for i = 1:N
    for j = 1:N

    end
```

**修改后**:
```matlab
%% 6. 信念广播：智能体之间共享信念

    for i = 1:N
        for j = 1:N
            Value_data(i).other{j}.initbelief = Value_data(j).initbelief;
        end
    end
end
```

**说明**:
- 当开关为 `false` 时，跳过信念广播
- 避免不必要的信念同步操作

## 功能说明

### 信念更新开关的作用

#### 启用信念更新 (`enable_belief_update = true`)
- **行为**: 算法在每轮迭代后根据观测结果更新智能体信念（贝叶斯更新）
- **适用场景**:
  - 任务需求未知或不确定
  - 需要通过观测逐步学习任务特性
  - 动态环境下的自适应决策
- **优势**: 能够根据实际观测调整决策，提高长期性能
- **劣势**: 计算开销较大，需要多轮迭代

#### 禁用信念更新 (`enable_belief_update = false`)
- **行为**: 算法仅使用初始信念进行计算，不进行信念更新
- **适用场景**:
  - 任务需求已知或可准确估计
  - 需要快速决策，不需要学习过程
  - 对比实验中作为基准算法
- **优势**: 计算速度快，逻辑简单
- **劣势**: 无法适应环境变化，依赖初始信念准确性

## 使用方法

### 在 Compare_Algorithms.m 中设置

```matlab
% 启用信念更新（默认）
AddPara.enable_belief_update = true;

% 或禁用信念更新
AddPara.enable_belief_update = false;
```

### 直接调用 Qi2023_main

```matlab
% 准备参数
AddPara = struct();
AddPara.enable_belief_update = false;  % 设置开关
AddPara.control = 1;
AddPara.resource_confidence = 0.95;

% 调用算法
[Value_data, history_data] = Qi2023_main(agents, tasks, AddPara, Value_Params);
```
