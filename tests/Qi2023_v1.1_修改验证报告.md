## 修改内容总结

### 1. 核心功能：信念更新开关

为 Qi2023 算法添加了信念更新开关，允许用户控制算法是否在每轮迭代后更新智能体的信念。

**开关参数**: `AddPara.enable_belief_update`
- `true` - 启用信念更新（默认）
- `false` - 禁用信念更新，仅使用初始信念

## 技术细节

### 信念更新机制

**启用时** (`enable_belief_update = true`):
1. 每轮执行观测：`AgentOps.collect_observations()`
2. 更新信念：`AgentOps.update_belief_from_observations()`
3. 广播信念：智能体之间共享更新后的信念
4. 下一轮基于新信念进行决策

**禁用时** (`enable_belief_update = false`):
1. 每轮执行观测（仍然观测，但不更新信念）
2. 跳过信念更新
3. 跳过信念广播
4. 所有轮次都使用初始信念进行决策

### 数据结构

**history_data 结构**:
```matlab
history_data.rounds(i).round_num              % 轮次编号
history_data.rounds(i).coalition_utility      % 总效用
history_data.rounds(i).total_global_cost      % 总成本
history_data.rounds(i).total_completed_value  % 完成任务价值
history_data.rounds(i).task_completion_degrees % 任务完成度
history_data.rounds(i).beliefs                % 信念快照
```
