## 🔍 核心差异分析

### 1. 算法范式差异

#### SA_Value：模拟退火（Simulated Annealing）
```
决策机制：
  - 顺序决策：智能体逐个决策
  - 二元操作：Join（加入）或 Leave（离开）
  - 局部搜索：基于当前状态的邻域搜索
  - 概率接受：通过温度参数控制接受劣解的概率
```

#### Qi2023：禁忌搜索 + 偏好引力（Tabu Search + Preference Gravity）
```
决策机制：
  - 全局视角：考虑所有智能体的联合效用
  - 禁忌机制：避免重复访问已探索的解
  - 偏好引力：基于多因素的智能概率分配
  - Boltzmann分布：动态调整探索与开发的平衡
```

---

### 2. 资源分配策略差异

#### SA_Value：基于缺口的概率分配

**Select_probs 函数逻辑：**
```matlab
// 计算因子：
1. 资源缺口（需求 - 当前分配）
2. 任务优先级
3. 距离成本
4. 智能体资源容量

// 概率计算：
prob(task) ∝ priority * gap / distance
```

**特点：**
- ✅ 简单直观
- ✅ 计算快速
- ❌ 未考虑队友效用
- ❌ 未考虑资源类型的差异化

#### Qi2023：偏好引力（Preference Gravity）

**Qi2023_Select_probs 函数逻辑：**
```matlab
// 偏好重力公式：
f_{m,n}^(z)(k) = (beta_m)^2 * c_m^(z) * agent_capacity / d_{m,n}

其中：
- beta_m: 任务优先级（归一化）
- c_m^(z): 资源缺口（归一化）
- agent_capacity: 智能体资源容量（归一化）
- d_{m,n}: 距离（归一化）

// Boltzmann分布：
p_{m,n}^(z)(k) = exp[f * Gamma] / sum(exp[f * Gamma])

其中 Gamma 从 1 增长到 100（动态调整）
```

**特点：**
- ✅ 多因素综合考虑
- ✅ 平方项增强优先级影响
- ✅ Boltzmann分布平滑概率
- ✅ Gamma参数动态调整探索/开发
- ✅ 每种资源类型独立计算概率

**关键优势：**
1. **平方项放大效应**：`(beta_m)^2` 使高优先级任务获得更多关注
2. **归一化处理**：所有因子都归一化到 [0,1]，避免数值不稳定
3. **动态Gamma**：从1增长到100，前期探索，后期开发
4. **资源类型差异化**：不同资源类型有不同的概率分布

### 3. 效用计算差异

#### SA_Value：Preference_gain（BMBT偏好计算）

**公式：**
```
Delta U = (Self_Q - Self_P) + Sum(Gain_g) - Sum(Loss_h) + Sum(Diff_o)

其中：
- Self_Q - Self_P: 自身效用变化
- Sum(Gain_g): 新加入任务的队友增益
- Sum(Loss_h): 退出任务的队友损失
- Sum(Diff_o): 维持任务的队友效用差
```

**特点：**
- ✅ 考虑队友效用（社会福利）
- ✅ 区分新增、退出、维持任务
- ❌ 需要估算队友信念（可能不准确）
- ❌ 计算复杂度高

#### Qi2023：直接效用计算

**公式：**
```
Delta U = U_new - U_old

其中：
U = calc_agent_total_utility(SC, agents, tasks, Value_Params, Value_data)
```

**特点：**
- ✅ 直接计算，准确性高
- ✅ 计算简单，速度快
- ❌ 不直接考虑队友效用（但通过禁忌搜索间接优化）

---

### 4. 搜索策略差异

#### SA_Value：顺序决策 + 温度控制

**流程：**
```
for each round:
    T = 1  // 初始温度
    while not converged:
        for each agent (顺序):
            尝试 Join 操作
            if Join 失败:
                尝试 Leave 操作

        检查收敛（连续20次无变化）
```

**特点：**
- ✅ 简单易实现
- ✅ 收敛快（平均23.55秒）
- ❌ 顺序决策可能陷入局部最优
- ❌ 后决策的智能体受前面决策影响大
- ❌ 温度参数未充分利用（代码中T=1固定）

#### Qi2023：禁忌搜索 + 全局优化

**流程：**
```
for each round:
    初始化禁忌表 TabuList = {}
    Gamma = 1  // 初始Boltzmann系数

    while not converged (最多100次迭代):
        for each agent (顺序):
            计算偏好引力概率
            执行资源交换操作（带可行性检查）
            更新全局SC

        计算新SC的哈希值
        if 在禁忌表中:
            跳过
        else:
            计算效用差 Delta U
            if Delta U > 0:
                接受新SC
                添加到禁忌表
                重置稳定计数器

        Gamma += k * (Gamma_max - Gamma) / K_max  // 动态增长

        检查收敛（连续20次无改进）
```

**特点：**
- ✅ 禁忌机制避免重复搜索
- ✅ 全局效用优化
- ✅ Gamma动态调整探索/开发
- ✅ 更多迭代次数（最多100次 vs SA的收敛即停）
- ❌ 计算时间长（49秒 vs 23.55秒）

## 💡 为什么 Qi2023 效用更高？

### 原因1：更智能的资源分配策略

**偏好引力的优势：**

1. **平方项放大高优先级任务**
   ```
   SA_Value: prob ∝ priority
   Qi2023:   prob ∝ (priority)^2

   示例：
   任务A: priority = 0.8 → SA: 0.8,  Qi: 0.64
   任务B: priority = 0.4 → SA: 0.4,  Qi: 0.16

   比例：
   SA:  A/B = 2.0
   Qi:  A/B = 4.0  ← 高优先级任务获得更多关注
   ```

2. **归一化处理避免数值问题**
   - 所有因子归一化到 [0,1]
   - 避免某个因子主导决策
   - 提高数值稳定性

3. **Boltzmann分布平滑概率**
   ```
   exp(f * Gamma) 使概率分布更平滑
   Gamma从1到100动态增长：
   - 前期：Gamma小，概率分布平坦，探索多样性
   - 后期：Gamma大，概率集中，开发最优解
   ```

---

### 原因2：禁忌搜索避免重复探索

**SA_Value的问题：**
```
可能反复在相同的联盟结构之间振荡：
Round 1: SC_A → SC_B
Round 2: SC_B → SC_A
Round 3: SC_A → SC_B
...
浪费计算资源，无法探索新区域
```

**Qi2023的解决：**
```
禁忌表记录已访问的SC：
TabuList = [hash(SC_1), hash(SC_2), ..., hash(SC_10)]

if hash(SC_new) in TabuList:
    跳过，尝试其他方向
else:
    接受并添加到禁忌表

结果：强制算法探索新区域，避免重复
```

---

### 原因3：更多的迭代次数

**迭代次数对比：**

| 算法 | 每轮最大迭代 | 收敛条件 | 实际迭代 |
|------|------------|---------|---------|
| SA_Value | 无限制 | 连续20次无变化 | ~30-50次 |
| Qi2023 | 100次 | 连续20次无改进 | ~60-80次 |

**Qi2023的优势：**
- 更多迭代 = 更充分的搜索
- 禁忌机制保证不浪费在重复搜索上
- 结果：找到更优的联盟结构

---

### 原因4：动态的探索/开发平衡

**SA_Value的问题：**
```matlab
T = 1  // 温度固定为1，未充分利用SA的温度机制
```

**Qi2023的优势：**
```matlab
Gamma = Gamma_init + k * (Gamma_max - Gamma_init) / K_max
// Gamma从1增长到100

效果：
- 前期（Gamma=1-20）：概率分布平坦，探索多样性
- 中期（Gamma=20-60）：逐渐聚焦，平衡探索/开发
- 后期（Gamma=60-100）：概率集中，开发最优解
```

**示例：**
```
假设两个任务的偏好重力：
f_A = 0.8, f_B = 0.4

Gamma = 1:
  p_A = exp(0.8) / (exp(0.8) + exp(0.4)) = 0.60
  p_B = 0.40
  → 分布较平坦，探索性强

Gamma = 50:
  p_A = exp(40) / (exp(40) + exp(20)) = 0.9999
  p_B = 0.0001
  → 分布集中，开发性强
```

---

### 原因5：资源类型差异化处理

**SA_Value：**
```matlab
// 所有资源类型使用相同的概率
probs = zeros(K, M);
for k = 1:K
    probs(k, :) = same_probability_for_all_resources;
end
```

**Qi2023：**
```matlab
// 每种资源类型独立计算概率
probs = zeros(K, M);
for z = 1:K
    for m = 1:M
        f_mn_z = (beta_m^2) * c_m_z * agent_capacity_z / d_mn;
        // 不同资源类型有不同的 c_m_z 和 agent_capacity_z
    end
    probs(z, :) = softmax(f_values * Gamma);
end
```

**优势：**
- 智能体可以根据自己的资源优势选择任务
- 例如：资源类型1充足 → 优先选择需要资源1的任务
- 结果：资源利用更高效
