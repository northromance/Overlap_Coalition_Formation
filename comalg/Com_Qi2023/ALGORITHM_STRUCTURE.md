# Qi2023 算法结构与计算方式详解

## 算法概述

**算法名称**: Preference Gravity-Guided Tabu Search (PGG-TS)
**应用场景**: 分布式重叠联盟形成 (Distributed Overlapping Coalition Formation)
**核心思想**: 结合偏好引力场、禁忌搜索和 Boltzmann 温度调节，引导智能体形成高效的任务联盟

---

## 算法流程图

```
┌─────────────────────────────────────────────────────────────┐
│                    初始化阶段 (Initialization)                │
├─────────────────────────────────────────────────────────────┤
│ 1. 设置参数: L_tabu=10, K_len=20, K_max=100, Γ=100, α=0.98 │
│ 2. 初始化禁忌表 Tabu_SC = {}                                 │
│ 3. 初始化联盟结构 SC = {M个空矩阵[N×K]}                      │
│ 4. 对每个智能体 n:                                           │
│    - 计算偏好引力 F_n(1) 和选择概率 P_n(1)                   │
│    - 基于 P_n(1) 分配初始资源到任务                          │
│ 5. 计算初始效用 U(1)                                         │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│                    主循环 (Main Loop)                         │
│                while k ≤ K_max AND k_stable ≤ K_len          │
├─────────────────────────────────────────────────────────────┤
│  对每个智能体 n = 1 to N:                                     │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ A. 离开操作 (Leave)                                    │  │
│  │    - 随机选择部分资源离开当前联盟                      │  │
│  │    - 离开概率 p_leave = 0.3                           │  │
│  └───────────────────────────────────────────────────────┘  │
│                            ↓                                  │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ B. 引力计算 (Gravity)                                  │  │
│  │    - 计算偏好引力 F_n(k)                              │  │
│  │      F[m,k] = (V_m × Rem_m,k) / dist²                 │  │
│  │    - 计算选择概率 P_n(k)                              │  │
│  │      P[m,k] = exp(F[m,k]/Γ) / Σexp(F[i,k]/Γ)         │  │
│  └───────────────────────────────────────────────────────┘  │
│                            ↓                                  │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ C. 交换操作 (Exchange)                                 │  │
│  │    - 基于概率 P 轮盘赌选择新任务                       │  │
│  │    - 将资源分配到选中的任务                            │  │
│  │    - 生成新联盟结构 SC_new                            │  │
│  └───────────────────────────────────────────────────────┘  │
│                            ↓                                  │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ D. 禁忌检查 (Tabu Check)                              │  │
│  │    - 计算 SC_new 的哈希值                             │  │
│  │    - 检查是否在禁忌表 Tabu_SC 中                       │  │
│  └───────────────────────────────────────────────────────┘  │
│                            ↓                                  │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ E. 效用判断 (Utility Check)                           │  │
│  │    IF SC_new ∉ Tabu_SC:                               │  │
│  │       计算 U_new = Evaluate(SC_new)                   │  │
│  │       IF U_new > U_current:                           │  │
│  │          SC ← SC_new                                  │  │
│  │          U_current ← U_new                            │  │
│  │          k_stable ← 0                                 │  │
│  │          将 SC_new 加入 Tabu_SC                        │  │
│  │       ELSE:                                            │  │
│  │          保持 SC 不变                                  │  │
│  │    ELSE:                                               │  │
│  │       拒绝 SC_new (在禁忌表中)                         │  │
│  └───────────────────────────────────────────────────────┘  │
│                                                               │
│  如果本轮无改进: k_stable ← k_stable + 1                     │
│                                                               │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ F. 温度更新 (Temperature Update)                       │  │
│  │    - Γ(k+1) ← α × Γ(k)  (降温)                        │  │
│  │    - 更新禁忌表 (FIFO队列)                             │  │
│  │    - k ← k + 1                                         │  │
│  └───────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│                    输出 (Output)                              │
├─────────────────────────────────────────────────────────────┤
│ 返回稳定的联盟结构 SC* 和历史数据 history_data               │
└─────────────────────────────────────────────────────────────┘
```

## 核心计算公式

### 1. 偏好引力 (Preference Gravity) - 公式 (26)

```
F_n^(z)[m, k] = (V_m × Rem_m,k) / (dist_n,m² + ε)
```

**符号说明**:
- `F_n^(z)[m, k]`: 智能体 n 对任务 m 的第 k 种资源的偏好引力
- `V_m`: 任务 m 的价值（期望价值）
- `Rem_m,k`: 任务 m 对第 k 种资源的剩余需求 = `Demand_m,k - Allocated_m,k`
- `dist_n,m`: 智能体 n 到任务 m 的欧氏距离
- `ε`: 小常数，防止除零（1e-6）

**物理意义**:
- 类似万有引力定律：`F = G × (m1 × m2) / r²`
- 任务价值越高、剩余需求越大、距离越近 → 引力越大
- 引导智能体优先选择高价值、近距离、需求未满足的任务

**代码实现**:
```matlab
for m = 1:M
    task_pos = [tasks(m).x, tasks(m).y];
    dist_sq = sum((agent_pos - task_pos).^2) + 1e-6;

    for k = 1:K
        current_allocated = sum(SC{m}(:, k));
        demand = tasks(m).resource_demand(k);
        rem_demand = max(0, demand - current_allocated);
        task_val = tasks(m).value;

        F(m, k) = (task_val * rem_demand) / dist_sq;
    end
end
```

### 2. 选择概率 (Selection Probability) - 公式 (27)

```
P_n^(z)[m, k] = exp(F_n^(z)[m, k] / Γ) / Σ_i exp(F_n^(z)[i, k] / Γ)
```

**符号说明**:
- `P_n^(z)[m, k]`: 智能体 n 选择任务 m 分配第 k 种资源的概率
- `Γ`: Boltzmann 温度系数（控制探索与利用的平衡）
- `Σ_i`: 对所有任务 i 求和（归一化）

**物理意义**:
- 基于 Boltzmann 分布的 Softmax 函数
- 高温 (Γ 大): 概率分布平坦，探索性强（接近均匀分布）
- 低温 (Γ 小): 概率集中在高引力任务，利用性强（接近贪婪选择）

**代码实现**:
```matlab
for k = 1:K
    vec = F(:, k);
    vec = vec - max(vec);  % 数值稳定性处理
    exp_vec = exp(vec / Gamma);
    sum_exp = sum(exp_vec);

    if sum_exp > 1e-12
        P(:, k) = exp_vec / sum_exp;
    else
        P(:, k) = ones(M, 1) / M;  % 均匀分布
    end
end
```

### 3. Boltzmann 温度更新 - 公式 (28)

```
Γ(k+1) = α × Γ(k)
```

**符号说明**:
- `Γ(k)`: 第 k 轮的温度
- `α`: 降温系数（0 < α < 1，通常取 0.95 ~ 0.99）

**温度演化示例** (Γ₀=100, α=0.98):
```
k=1:   Γ=100.00  (高温，大量探索)
k=10:  Γ=81.71
k=20:  Γ=66.76
k=50:  Γ=36.42
k=100: Γ=13.26   (低温，主要利用)
```

**代码实现**:
```matlab
Gamma = Gamma * alpha;  % 每轮降温
```

### 4. 效用评估 (Utility Evaluation)

```
U = Σ_m (V_m × D_C,m) - Σ_n Cost_n
```

**符号说明**:
- `U`: 全局净效用
- `V_m`: 任务 m 的价值
- `D_C,m`: 任务 m 的完成度（0 ~ 1）
- `Cost_n`: 智能体 n 的总成本（飞行 + 等待 + 执行）

**完成度计算**:
```
D_C,m = min(1, min_k(Allocated_m,k / Demand_m,k))
```
- 木桶效应：完成度由最短板资源决定
- 如果某种资源未满足需求，则任务无法完成

**代码实现**:
```matlab
% 在 UtilityEvaluator.evaluate_coalition_metrics 中实现
[global_net_utility, total_cost, total_value, completion_degrees] = ...
    UtilityEvaluator.evaluate_coalition_metrics(SC_global, agents, tasks, Value_Params, eps_val);
```

## 关键数据结构

### 1. 联盟结构 SC (Coalition Structure)

```matlab
SC = cell(M, 1);  % M 个任务
for m = 1:M
    SC{m} = zeros(N, K);  % N 个智能体 × K 种资源
end
```

**含义**:
- `SC{m}(n, k)`: 智能体 n 在任务 m 上投入的第 k 种资源量
- 例如: `SC{3}(2, 4) = 2.5` 表示智能体2在任务3上投入2.5单位的资源4

**示例**:
```
任务1的资源分配 SC{1}:
        资源1  资源2  资源3  资源4
智能体1   2      0      1      0
智能体2   0      3      0      2
智能体3   1      1      0      1
智能体4   0      0      2      0
```

### 2. 禁忌表 Tabu_SC

```matlab
TabuList = {'hash1', 'hash2', ..., 'hash_L_tabu'};
```

**含义**:
- 存储最近 L_tabu 个访问过的联盟结构的哈希值
- FIFO 队列：新结构加入时，最旧的结构被移除
- 防止算法在相同结构间循环

**哈希生成**:
```matlab
function hash_str = get_SC_hash(SC)
    temp_vec = [];
    for m = 1:length(SC)
        temp_vec = [temp_vec; SC{m}(:)];
    end
    hash_str = mat2str(temp_vec);
end
```

### 3. 历史数据 history_data

```matlab
history_data(k).SC = SC_global;
history_data(k).utility = current_utility;
history_data(k).iteration = k;
```

**用途**:
- 记录每轮的联盟结构和效用
- 用于绘制收敛曲线
- 用于分析算法性能

## 算法参数调优指南

### 1. 禁忌表长度 L_tabu

| 值 | 效果 | 适用场景 |
|----|------|----------|
| 5-10 | 短期记忆，快速探索 | 小规模问题 (M<10, N<5) |
| 10-20 | 平衡记忆，标准配置 | 中等规模问题 (M=10-20, N=5-10) |
| 20-50 | 长期记忆，深度搜索 | 大规模问题 (M>20, N>10) |

**建议**: `L_tabu = max(10, M/2)`

### 2. 稳定阈值 K_len

| 值 | 效果 | 适用场景 |
|----|------|----------|
| 10-15 | 快速收敛，可能早停 | 时间敏感应用 |
| 20-30 | 平衡收敛，标准配置 | 一般应用 |
| 30-50 | 充分收敛，高质量解 | 质量优先应用 |

**建议**: `K_len = 20`

### 3. 初始温度 Γ₀

| 值 | 效果 | 适用场景 |
|----|------|----------|
| 50-100 | 中等探索 | 标准配置 |
| 100-200 | 大量探索 | 复杂地形，多局部最优 |
| 10-50 | 少量探索 | 简单问题，快速收敛 |

**建议**: `Γ₀ = 100`

### 4. 降温系数 α

| 值 | 效果 | 适用场景 |
|----|------|----------|
| 0.95 | 快速降温 | 迭代次数少 (K_max<50) |
| 0.98 | 标准降温 | 标准配置 (K_max=50-100) |
| 0.99 | 缓慢降温 | 迭代次数多 (K_max>100) |

**建议**: `α = 0.98`

### 5. 离开概率 p_leave

| 值 | 效果 | 适用场景 |
|----|------|----------|
| 0.1-0.2 | 小幅调整 | 接近最优解时 |
| 0.3-0.4 | 中等调整 | 标准配置 |
| 0.5-0.7 | 大幅调整 | 初期探索阶段 |

**建议**: `p_leave = 0.3`

## 算法复杂度分析

### 时间复杂度

**单轮迭代**:
- 离开操作: O(N × M × K)
- 引力计算: O(N × M × K)
- 交换操作: O(N × M × K)
- 禁忌检查: O(L_tabu × M × N × K)
- 效用评估: O(M × N × K)

**总复杂度**: O(K_max × N × M × K × L_tabu)

**典型场景** (N=6, M=10, K=6, K_max=100, L_tabu=10):
- 单轮: ~36,000 次基本操作
- 总计: ~3,600,000 次基本操作
- 运行时间: 1-5 秒 (MATLAB)

### 空间复杂度

- 联盟结构 SC: O(M × N × K)
- 禁忌表: O(L_tabu × M × N × K)
- 历史数据: O(K_max × M × N × K)

**总空间**: O(K_max × M × N × K)

## 算法优缺点

### 优点

1. **全局搜索能力强**: 禁忌搜索避免局部最优
2. **自适应性好**: Boltzmann 温度自动平衡探索与利用
3. **分布式友好**: 每个智能体独立决策，易于并行化
4. **鲁棒性强**: 对初始解不敏感

### 缺点

1. **参数敏感**: 需要调优 L_tabu, K_len, Γ₀, α, p_leave
2. **计算开销大**: 禁忌表检查和效用评估耗时
3. **内存占用高**: 需要存储禁忌表和历史数据
4. **收敛速度慢**: 相比贪婪算法，需要更多迭代

## 常见问题 (FAQ)

**Q1: 为什么效用有时会下降？**
A: 这是正常现象。禁忌搜索允许接受非改进解以跳出局部最优，但只要不在禁忌表中。

**Q2: 如何加快收敛速度？**
A: 减小 K_len，增大 α（更快降温），减小 L_tabu。

**Q3: 如何提高解的质量？**
A: 增大 K_max，减小 α（更慢降温），增大 K_len。

**Q4: 禁忌表太大会怎样？**
A: 内存占用增加，检查时间变长，但搜索多样性提高。

**Q5: 如何处理大规模问题？**
A: 使用更高效的哈希函数（如 MD5），考虑并行化，减小 L_tabu。
