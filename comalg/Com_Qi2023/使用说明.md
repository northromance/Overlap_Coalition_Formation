## 📖 算法说明

### 算法名称
**PGG-TS**: Preference Gravity-Guided Tabu Search
（偏好引力引导的禁忌搜索算法）

### 核心思想
1. **偏好引力场**: 任务对智能体的吸引力 = (价值 × 剩余需求) / 距离²
2. **禁忌搜索**: 维护禁忌表，避免重复访问相同结构
3. **温度调节**: Boltzmann 温度控制探索与利用的平衡

### 算法流程
```
初始化 → 主循环 → 输出
         ↓
    对每个智能体:
    1. Leave: 随机离开部分资源
    2. Gravity: 计算偏好引力和概率
    3. Exchange: 基于概率重新分配
    4. Tabu: 检查禁忌表
    5. Utility: 判断是否接受
    6. Update: 更新温度和禁忌表
```

## ⚙️ 参数说明

### 默认参数（已优化）
```matlab
L_tabu = 10;     % 禁忌表长度
K_len = 20;      % 稳定阈值（连续20轮无改进则停止）
K_max = 100;     % 最大迭代次数
Gamma = 100;     % 初始温度
alpha = 0.98;    % 降温系数
p_leave = 0.3;   % 离开概率
```

### 参数调优建议

**追求速度**（快速收敛）:
```matlab
K_len = 10;      % 降低稳定阈值
alpha = 0.95;    % 加快降温
```

**追求质量**（高质量解）:
```matlab
K_len = 30;      % 提高稳定阈值
alpha = 0.99;    % 减慢降温
K_max = 200;     % 增加最大迭代次数
```

## ❓ 常见问题

### Q1: 如何验证算法是否正确安装？
```matlab
cd tests
test_Qi2023  % 应该看到所有测试通过
```

### Q2: 算法运行很慢怎么办？
- 减小 `K_max`（最大迭代次数）
- 减小 `K_len`（稳定阈值）
- 增大 `alpha`（加快降温）

### Q3: 效用没有提升怎么办？
- 增大 `K_max`（允许更多迭代）
- 减小 `alpha`（减慢降温，更多探索）
- 检查初始资源是否充足

### Q4: 如何查看算法运行过程？
算法会自动输出每轮的信息：
```
[Qi2023] Round 1: Utility = 1787.66, Stability = 1, Temp = 98.00
[Qi2023] Round 2: Utility = 1885.05, Stability = 0, Temp = 96.04
...
```

### Q5: 如何绘制效用演化曲线？

utilities = arrayfun(@(x) x.utility, history_data);
plot(utilities, 'LineWidth', 2);
xlabel('Iteration');
